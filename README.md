# 昆特牌 · 单机版

巫师 3 原版规则的单机昆特牌。整个游戏是**一个 HTML 文件**，没有构建步骤、没有外部依赖、没有网络请求，双击即玩，也可以直接丢到任何静态托管上。

👉 **[在线试玩](https://lynch715.github.io/gwent/)**

## 规则

三局两胜。每局双方轮流出牌，先跳过的一方停止出牌，另一方可以继续加码；双方都跳过后比较总威力，低的一方失去一颗宝石，失去两颗即告负。

开局各抽 10 张牌，可调度 2 张。整局对弈只有这些牌，用完就没有了——何时跳过保牌，是昆特牌的核心。

战场分近战、远程、攻城三排，单位只能放入对应的排，「灵活」单位可选近战或远程。结算顺序是天气 → 紧密联结 / 士气 → 指挥官号角；英雄免疫天气、烈焰与诱饵，但仍受号角与士气加成。

## 内容

四大阵营共 123 张卡，含英雄、间谍、医师、集结、紧密联结、士气、号角、诱饵、烈焰与天气牌，以及四位领袖和各阵营特性：

| 阵营 | 特性 | 领袖能力 |
| --- | --- | --- |
| 北方王国 | 每赢下一局，从牌组抽一张牌 | 攻城排全体威力翻倍 |
| 尼弗迦德 | 平局时判定为你获胜 | 从墓场召回一张单位牌 |
| 松鼠党 | 由你决定谁先手 | 对方远程排 ≥10 时摧毁其中最强单位 |
| 怪物 | 每局结束后随机保留一个己方单位 | 近战排全体威力翻倍 |

牌组可以自由组建，规则校验「至少 22 张单位牌、最多 10 张特殊牌」，改动保存在浏览器本地。

## AI

对手会对每种打法做一次推演来评分，同时权衡分差与牌差，所以它会先扔间谍换牌、在首局大幅落后时果断跳过保牌、等你打出大牌再用烈焰、只在天气对自己有利时才放天气。

对「总是打最大牌」的贪婪基准，400 局胜率约 62%；对随机出牌约 73%。

## 美术

卡面插画是 38 幅手写的内联 SVG 剪影（骑士盔、投石机、法师、飞龙、鹰身女妖、狼人……），按卡牌类型映射，配阵营色的月夜背景。没有一张位图，所以整个游戏仍然是单文件。

## 操作

电脑上鼠标悬停任意卡牌会在旁边浮出大图与能力说明，点击出牌。手机上点一下卡牌弹出详情，再点「出牌」确认；竖屏空排会自动收窄，横屏把信息栏移到左侧竖栏，侧栏日志收进右滑抽屉。

## 本地运行

克隆后直接用浏览器打开 `index.html` 即可，不需要起服务器。
